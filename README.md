# AI-Based-Virtual-Interaction-System
Gesture and Voice Controlled Human-Computer Interaction System using MediaPipe, OpenCV, Flask, and Speech Recognition.
## Overview

This project presents an Adaptive Accessibility System that enables users to interact with a computer using both hand gestures and voice commands.

The system combines computer vision, speech recognition, and machine learning techniques to create a hands-free and accessible user experience.

## Technologies

- Python
- OpenCV
- MediaPipe
- Flask
- SpeechRecognition
- PyAutoGUI
- Sentence-BERT (SBERT)

## Features

- Gesture-based mouse control
- Voice-controlled typing
- Application control through speech
- Volume and brightness adjustment
- Real-time interaction logging
- Web-based monitoring dashboard
